# 学员任务与提交要求

本仓库只提供可运行的 PX4/Gazebo 环境，不提供任务解法。允许查阅并引用 PX4、ROS 2、Gazebo 官方文档；提交时要说明参考来源，且能在面试中解释自己的代码。所有飞行必须由 PX4 控制，禁止通过 Gazebo `set_pose`、模型移动命令或视频后期合成代替飞行。

## 26 级：基础往返

自行编写 ROS 2 节点，令 x500 从黄色 A 坪起飞、飞向蓝色 B 点、返回 A、降落并解除解锁。B 的视觉标记在 Gazebo ENU `(7, 0)` 附近；规划前先确认 PX4 NED 坐标及实际位置反馈。请实现基于真实位置的到点判定、连续 Offboard 控制信号、阶段超时与失败处理。建议控制高度约 2.5–3 m；允许在合理安全范围内调整路线。预计准备 2–4 天。

## 25 级：可配置航线

在同一环境中实现 A→B→C→A。C 由本人选择，需给出坐标与避障理由。航点与飞行参数应从配置读取，至少演示两组配置；加入速度限制、单段超时，以及通信/模式异常的一种恢复或安全终止策略。预计准备 3–5 天。

## 统一提交

1. 代码、依赖说明、启动命令与约 300 字设计说明。
2. 连续 Gazebo 画面或原生仿真摄像机录像，以及 PX4 实际位置/状态记录；仅有视频不算完成。
3. 成功与失败的判定依据、至少一次遇到的问题及处理过程。

面试将重点讨论：坐标系、为什么要持续发送 Offboard 信号、如何判断真正到点、何时允许切换阶段、如何安全降落、仿真结果不能直接推广到真机的原因。

可参考 [PX4 ROS 2 入门](https://docs.px4.io/v1.16/en/ros2/user_guide)、[Offboard 控制说明](https://docs.px4.io/v1.16/en/flight_modes/offboard) 和 [ROS 2 Python 包教程](https://docs.ros.org/en/humble/Tutorials/Beginner-Client-Libraries/Creating-Your-First-ROS2-Package.html)。这些公开材料不是仓库内的现成答案。
